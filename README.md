# sh-scripts

常用 Shell 脚本集合，主要面向 Linux 运维场景（多盘批量操作、sudo 免密配置等）。

所有脚本都要求：Linux / bash / 需要 root 权限的操作通过 sudo 执行。

## 脚本清单

| 脚本 | 用途 |
|---|---|
| `多盘并行零填写入.sh` | 按参数指定的盘符，同时启动多个 `dd if=/dev/zero` 清零写入，输出写日志 |
| `多盘进度看板.sh` | 读取上一步的日志，N 行原地跳动刷新 dd 进度，不刷屏、不进任何界面 |
| `永久免密设置.sh` | 给当前用户配置 sudo 永久免密（写入 `/etc/sudoers.d/`），可撤销、可检查 |
| `临时免密设置.sh` | 刷新当前终端的 sudo 时间戳（默认 15 分钟），不改任何配置文件 |

## 使用方法

```bash
chmod +x *.sh

# 1) 启动多盘并行清零（盘符数量不限）
./多盘并行零填写入.sh sdb sdc sdd sde

# 2) 另开一个终端，看进度（原地刷新 4 行）
./多盘进度看板.sh sdb sdc sdd sde

# 3) 停止指定盘
./多盘并行零填写入.sh --stop sdb sdc

# 4) 查看某几个盘的当前进度（一次性输出）
./多盘并行零填写入.sh --status sdb sdc
```

### 多盘并行零填写入.sh

```
./多盘并行零填写入.sh [选项] 盘符1 盘符2 ...

选项:
  --bs 24M          每次写入的块大小，默认 24M
  --log-dir /tmp    进度日志目录，默认 $DD_LOG_DIR 或 /tmp
  --stop            停止指定盘上正在运行的 dd
  --status          打印指定盘的当前进度（取日志最后一行）
  -h, --help        显示帮助
```

特点：
- 盘符完全由参数传入，写死列表是不存在的；1 个盘到 N 个盘都能用。
- 每个盘独立进程、独立日志：`/tmp/dd_<盘>.log`。
- 启动前会检查 `/dev/<盘>` 是否为块设备、该盘是否已有 dd 在跑，避免重复操作。

### 多盘进度看板.sh

```
./多盘进度看板.sh [选项] 盘符1 盘符2 ...

选项:
  --interval 1      刷新间隔（秒），默认 1
  --log-dir /tmp    日志目录，需与写入脚本一致
  -h, --help        显示帮助
```

特点：
- 屏幕上固定 N 行，每行对应一个盘，数字原地跳动，不滚动刷屏。
- 显示内容是 dd 的原生进度文本，例如：
  `sdb 4227858432 bytes (4.2 GB, 3.9 GiB) copied, 18 s, 234 MB/s`
- Ctrl+C 只退出看板，**不影响后台正在跑的 dd**。

### 永久免密设置.sh

```
./永久免密设置.sh             # 设置（写入 /etc/sudoers.d/010-<用户>-nopasswd）
./永久免密设置.sh --remove    # 撤销（删除该文件）
./永久免密设置.sh --check     # 检查当前是否已免密
```

- 写入前用 `visudo -cf` 做语法校验，校验不过不会落盘。
- 只新增自己的文件，不动 `/etc/sudoers` 与其它 `sudoers.d` 条目。
- ⚠️ 风险提示：开启后，任何能以该账号登录本机的人等同拥有 root 权限。

### 临时免密设置.sh

```
./临时免密设置.sh             # 刷新当前终端的时间戳（会问一次密码）
./临时免密设置.sh --cancel    # 立即取消
./临时免密设置.sh --check     # 检查是否仍在有效期内
```

- 只对当前终端（tty）有效，默认 15 分钟（受 sudoers 的 `timestamp_timeout` 控制）。
- 换终端、重连 SSH、超时后需重新执行。
- 不修改任何配置文件。

## 注意事项

1. **`多盘并行零填写入.sh` 是破坏性操作**：`dd if=/dev/zero` 会抹掉目标盘上的全部分区与数据，执行前务必用 `lsblk` 确认盘符。
2. 建议先用 `lsblk -d -o NAME,SIZE,MODEL,SERIAL` 核对磁盘型号与序列号，避免选错盘。
3. 多盘并行写入会产生较大 I/O 压力，请确认目标机器与存储链路能承受。
4. 脚本按单机本地执行设计，不依赖任何外部服务。
5. 每块盘的容量不同时，先写完的 dd 会自行结束，看板对应行会停在最后一次进度上。

## 环境要求

- Linux（已在 Ubuntu 24.04 / kernel 6.8 上验证）
- bash 4+
- coreutils（dd）、procps（pgrep/watch）、sudo
- 使用时需具备 sudo 权限
