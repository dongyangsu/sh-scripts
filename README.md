# sh-scripts

常用 Shell 脚本集合，面向 Linux 运维场景：多盘批量清零（dd）、进度展示、sudo 免密配置。
所有脚本的盘符均由命令行参数传入，数量不限，没有写死的设备列表。

## 脚本清单

### 磁盘操作

| 脚本 | 用途 | 何时用 |
|---|---|---|
| `多盘清零前体检.sh` | 只读检查：块设备/容量/型号/序列号/挂载/扇区/SMART | 清零前先确认盘没选错 |
| `多盘并行零填写入.sh` | 后台并行启动 dd，每盘独立日志，支持 `--stop` / `--status` | 想后台跑、随时停单盘 |
| `多盘进度看板.sh` | 读取日志，N 行原地刷新进度 | 另开终端看并行进度 |
| `多盘清零单窗看板.sh` | 启动 + 看板二合一，前台一条命令 | 不想开第二个终端 |
| `多盘顺序零填写入.sh` | 一块写完再写下一块 | 并行容易掉盘/链路不稳的机器 |

### sudo 免密

| 脚本 | 用途 | 何时用 |
|---|---|---|
| `免密状态总览.sh` | 只读诊断：永久免密 / 临时免密 / 需要密码 | 先搞清楚现在是什么状态 |
| `永久免密设置.sh` | 给**当前用户**写 sudoers 永久免密，可 `--remove` / `--check` | 长期免密 |
| `临时免密设置.sh` | 刷新当前终端 sudo 时间戳（默认 15 分钟），可 `--cancel` | 只临时用一会儿 |
| `指定用户免密设置.sh` | 给**指定用户**配置/撤销永久免密 | 给别的账号配 |

## 快速开始

```bash
chmod +x *.sh

# 1) 清零前体检（只读，先确认盘符对）
./多盘清零前体检.sh --smart sdb sdc sdd sde

# 2A) 并行版：后台启动 + 另一个终端看进度
./多盘并行零填写入.sh sdb sdc sdd sde
./多盘进度看板.sh sdb sdc sdd sde

# 2B) 并行版：单窗口二合一
./多盘清零单窗看板.sh sdb sdc sdd sde

# 2C) 顺序版：逐盘写入（链路不稳时用这个）
./多盘顺序零填写入.sh sdb sdc sdd sde

# 3) 停止/查看
./多盘并行零填写入.sh --stop sdb sdc
./多盘并行零填写入.sh --status sdb sdc
```

### 多盘清零前体检.sh

```
./多盘清零前体检.sh [--smart] 盘符1 盘符2 ...
  --smart   额外读取 SMART 关键属性（05/197/198/199，SAS 盘看 G-list）
```
- 纯只读，不写盘。
- 如果发现某块盘「已挂载」或「不是块设备」，会标红并返回非 0。
- 注意：盘符在热插拔/重启后会变，**每次清零前都要重新体检**。

### 多盘并行零填写入.sh

```
./多盘并行零填写入.sh [--bs 24M] [--log-dir /tmp] [--stop|--status] 盘符1 盘符2 ...
```
- 每盘一个独立 dd 进程 + 独立日志 `$DD_LOG_DIR/dd_<盘>.log`（默认 `/tmp`）。
- 启动前会检查：是否为块设备、该盘是否已有 dd 在跑。
- `--stop` 先 TERM 后 KILL；`--status` 打印日志最后一行。

### 多盘进度看板.sh

```
./多盘进度看板.sh [--interval 1] [--log-dir /tmp] 盘符1 盘符2 ...
```
- 固定 N 行、原地跳动刷新，显示 dd 原始进度文本。
- Ctrl+C 只退出看板，后台 dd 不受影响。

### 多盘清零单窗看板.sh

```
./多盘清零单窗看板.sh [--bs 24M] [--interval 1] 盘符1 盘符2 ...
```
- 前台一条命令：内部启动 dd，同时在当前终端刷新进度。
- Ctrl+C 退出看板，dd 继续；要停用 `多盘并行零填写入.sh --stop`。

### 多盘顺序零填写入.sh

```
./多盘顺序零填写入.sh [--bs 24M] [--force] 盘符1 盘符2 ...
```
- 逐盘顺序执行，适合「多盘并发时容易掉线」的机器。
- 默认跳过已挂载的盘（`--force` 可强制）。
- 结束打印成功/失败/跳过汇总。

### 免密状态总览.sh

```
./免密状态总览.sh
```
- 只读：当前用户/终端、`sudo -n` 即时判断、sudoers.d 里的 NOPASSWD 文件、
  /etc/sudoers 主文件规则、timestamp_timeout 配置、最终结论。

### 永久免密设置.sh

```
./永久免密设置.sh [--remove|--check]
```
- 写 `/etc/sudoers.d/010-<当前用户>-nopasswd`，`visudo -cf` 校验后才落盘。
- 只新增自己的文件，不改动 `/etc/sudoers` 和其它 `sudoers.d` 条目。
- ⚠️ 开启后，任何能以该账号登录本机的人都等同 root。

### 临时免密设置.sh

```
./临时免密设置.sh [--cancel|--check]
```
- 刷新当前终端（tty）的 sudo 时间戳，默认 15 分钟有效。
- 不改任何配置文件；换终端或重连 SSH 后需要重新执行。

### 指定用户免密设置.sh

```
./指定用户免密设置.sh <用户名> [--remove|--check]
```
- 与「永久免密设置.sh」的区别：可指定任意已存在用户。
- 需以 root 或具备 sudo 权限的账号执行。

## 注意事项

1. **dd 清零是破坏性操作**：`dd if=/dev/zero` 会抹掉目标盘的全部分区与数据。
   执行前先跑 `多盘清零前体检.sh` 或用 `lsblk -d -o NAME,SIZE,MODEL,SERIAL` 核对序列号。
2. 盘符会在热插拔/重启后变化，**不要复用上一次的盘符习惯**，每次都要重新确认。
3. 多盘并行产生较大 I/O 与供电压力；如果出现 `device offline` / `DID_NO_CONNECT`，
   首先怀疑线缆、背板、供电和 HBA，而不是脚本 —— 可改用顺序版降低压力。
4. 进程被 kill 或链路掉线后，dd 会以非 0 退出；日志里能看到最后写入量。
5. 脚本按单机本地执行设计，不依赖任何外部服务。

## 环境要求

- Linux（Ubuntu 24.04 / kernel 6.8 实测）
- bash 4+
- coreutils（dd、blockdev）、util-linux（lsblk、findmnt）、procps（pgrep）
- sudo；SMART 检查需要 smartmontools（可选）
